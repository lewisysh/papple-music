    간단한 사용법
    
        
      
          
    1. 로그인Wrapper 탭에서 Apple ID로 로그인하거나, 설정에서 Apple Music 쿠키를 넣으세요. 무손실(ALAC)은 wrapper가 필요해요.
      2. 
          
    2. 찾기검색창에 아티스트·곡·앨범 이름을 치거나 Apple Music 링크를 붙여넣으세요.
      3. 
          
    3. 듣기재생 버튼을 누르거나 곡을 더블클릭하면 바로 들을 수 있어요. 플레이어의 음질 배지를 누르면 AAC와 무손실 중에 고를 수 있어요.
      4. 
          
    4. 받기다운로드 버튼을 누르고 음질을 고르면 다운로드 탭에 추가되고, 진행률과 지금 하는 작업이 실시간으로 보여요.
      5. 
          
    5. 정리앨범은 Albums, 플레이리스트는 Playlists, 한 곡은 Songs 폴더에 저장돼요. 저장 위치와 파일 이름은 설정에서 바꿀 수 있어요.
      6. 
        
    
        
    스페이스바로 재생·일시정지하고, 곡을 오른쪽 클릭하면 다음에 재생·앨범으로 이동 같은 메뉴가 열려요.
